## Reporting a Vulnerability

The Escrow-FairLance Protocol team takes the security of smart contracts, cryptographic implementations, and user funds seriously.

If you discover a security vulnerability in this web client or our Soroban smart contracts, **please do not disclose it publicly via GitHub Issues**.

Instead, please send an encrypted or private email to:
**security@escrow-fairlance.org**

### Please Include:
1. Description of the vulnerability and attack vector.
2. Steps to reproduce or proof-of-concept (PoC) code.
3. Affected components (e.g. client XDR builder, deliverable encryption, wallet adapter).
4. Potential impact on user funds or privacy.

We acknowledge receipt of vulnerability reports within 48 hours and provide regular status updates until resolution.
